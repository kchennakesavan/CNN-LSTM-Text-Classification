# CNN vs LSTM for Sentiment Analysis

## Project Overview

This project compares Convolutional Neural Network (CNN) and Long
Short-Term Memory (LSTM) models for binary sentiment classification of
IMDB movie reviews. The models classify reviews as **Positive** or
**Negative**.

## Objectives

-   Build CNN and LSTM models for text sentiment classification.
-   Train and evaluate both models on the IMDB movie review dataset.
-   Compare test accuracy, precision, recall, F1-score, and training
    time.
-   Visualize and save the comparison results.

## Dataset

The project uses the IMDB movie review dataset provided through
`tensorflow.keras.datasets.imdb`.

-   Training samples: 25,000
-   Testing samples: 25,000
-   Classes: Positive and Negative
-   Maximum review sequence length: 200 tokens (padded/truncated)

## Models

### CNN

The CNN model uses an embedding layer, one-dimensional convolution,
global max pooling, and dense output layers to learn useful patterns in
review text.

### LSTM

The LSTM model uses an embedding layer and an LSTM recurrent layer to
learn sequential patterns in review text, followed by dense output
layers for classification.

## Results

  Metric                      CNN            LSTM
  --------------- --------------- ---------------
  Test Accuracy            85.02%          62.57%
  Precision                0.8848          0.5750
  Recall                   0.8053          0.9634
  F1-score                 0.8432          0.7202
  Training Time     18.33 seconds   25.86 seconds

**Result:** In this experiment, CNN achieved higher test accuracy and
F1-score, and trained faster than LSTM. LSTM achieved higher recall, but
its overall test accuracy was lower. These results reflect this
particular model configuration and run.

## Conclusion

For the current experiment, CNN performed better overall than LSTM on
test accuracy (85.02% vs. 62.57%) and F1-score (0.8432 vs. 0.7202),
while also taking less training time. The comparison demonstrates how
different neural network architectures can behave differently on the
same text classification task.
